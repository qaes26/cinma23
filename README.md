---

## 📽️ مميزات سينما شادية
- **المؤثرات السينمائية**: ستائر مخملية فاخرة تُفتح بسلاسة، مع عد تنازلي كلاسيكي للسينما القديمة (3... 2... 1...).
- **الفيديو والأغنية**: مشغل فيديو متزامن مع الأغنية الرومانسية (`song.webm`) في الخلفية، مع إمكانية استبدال الفيديو من الهاتف وحفظه عبر IndexedDB.
- **ظلال العشاق (Silhouette)**: رسم متجهي فاخر بأسفل الشاشة مع انعكاس ضوء الشاشة على تفاصيل العاشقين.
- **الإضاءة والأجواء**: تحكم كامل بإضاءة القاعة (تشغيل / إطفاء) مع جسيمات ذهبية وقلوب متحركة وشعاع بروجكتر واقعي.
